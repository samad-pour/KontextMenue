# KontextMenue

Ein Visual-Studio-Projekt zur Umsetzung eines Kontextmenüs als Bestandteil einer grafischen Benutzeroberfläche.

## Beschreibung

Das Projekt **KontextMenue** beschäftigt sich mit der Implementierung und Verwendung eines Kontextmenüs. Kontextmenüs ermöglichen es, bestimmte Aktionen direkt über ein situationsabhängiges Menü aufzurufen, beispielsweise durch einen Rechtsklick.

## Funktionen

- Darstellung eines Kontextmenüs
- Benutzerinteraktion über Menüpunkte
- Ausführung von Aktionen durch Menüauswahl
- Integration in eine grafische Benutzeroberfläche

## Technologien

- Microsoft Visual Studio
- .NET-Projektmappe

## Installation und Ausführung

1. Repository klonen:

   ```bash
   git clone https://github.com/samad-pour/KontextMenue.git
   ```

2. Die Datei `KontextMenue.sln` in Visual Studio öffnen.
3. Das Projekt erstellen.
4. Die Anwendung mit `F5` starten.
